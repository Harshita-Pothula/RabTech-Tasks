# Keyboard check for our own app

Run before every PR that touches `client/`.

- [ ] First Tab shows "Skip to main content"; Enter moves focus to main content
- [ ] Every link, input and button is reachable with Tab in visual order
- [ ] Focus outline is always visible
- [ ] Submitting an empty form moves focus to the input and the error is read out
- [ ] Result is announced by a screen reader (aria-live) without moving focus
- [ ] No keyboard traps
